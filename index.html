3D Hardware Acceleration Required

DrawRef uses 3D graphics (WebGL) to render interactive models in your browser. Your browser or device does not support WebGL, or it has been disabled.

If you're using Safari — Lockdown Mode may be blocking WebGL.

To add this site as an exception in Safari Lockdown Mode:

  1. Open Safari Settings (or Preferences)
  2. Go to the Websites tab
  3. Select Lockdown Mode in the sidebar
  4. Find drawref.app in the list (or visit the site first)
  5. Change its setting to "Off" (Allow)
  6. Reload this page

Other common causes:

  1. Browser extensions blocking WebGL (try disabling ad-blockers or privacy extensions)
  2. Outdated or unsupported browser — update to the latest version of Chrome, Edge, Firefox, or Safari
  3. GPU driver issues — update your graphics drivers
  4. Virtual machine or remote desktop may not support hardware-accelerated 3D
